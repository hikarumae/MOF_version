# 📄 AI文書管理システム：自動仕分け＆版管理

Azure Storage にアップロードされた PDF を GPT-4o が解析し、自動で整理します。

---

## 🚀 導入・設定ガイド

### 1. 環境変数の設定 (App Service)
- **AZURE_STORAGE_CONNECTION_STRING** : ストレージの接続文字列
- **AZURE_OPENAI_ENDPOINT** : OpenAIのエンドポイント
- **AZURE_OPENAI_API_KEY** : OpenAIのAPIキー（※KEYではなくAPI_KEYに修正済み）

<br>

### 2. ファイル構成の役割
- `main_app.py` : Flaskサーバー兼、常時監視ループ。
- `ai_judge.py` : 文書の判定ロジック。ここで「自社」ルールを管理。
- `pdf_analyzer.py` : PDF からのテキスト・画像抽出処理。
- `blob_organizer.py` : ファイルの移動とDB更新を担当。

---

## ⚖️ 仕分けルール（名寄せ）
AIは以下のルールに従って `target_entity`（会社名）を決定します：
1. **契約書** : 文書内から抽出した会社名（株式会社等は除外）。
2. **就業規則 / 職務権限基準** : 一律で **「自社」** に固定。
これにより、社内規定がバラバラに登録されるのを防ぎます。

---

## 🛠 カスタマイズ方法
- ai_judge.py 内の 【厳格ルール】 と 【出力要件】 の JSON 構造を修正してください。
-- 例: 「見積書」をカテゴリに追加したい場合は、プロンプトの選択肢に「見積書」を追記します。

- 監視の間隔を変えたい場合
-- main_app.py 内の time.sleep(10) の数値を調整してください。

---

## ⚠️ デプロイ時の注意
- コード変更後は **App Service を一度停止してからデプロイ** してください。
